# Nothing lost — MangaDex, 3.x wrapper → contract 4.0.0

`Plan-2026Q4-tracker-plugin-standardization.md` Phase 4.1. Every public method of the 3.x wrapper
(`api-wrapper-mangadex.cjs` at the tag `contract-3-final`) has exactly one row, classified **contract** (a §2
method the SDK's facade now generates, its source call in the client and its translation in the mapping),
**to client**, **to mapping**, or **deleted** (with the host call site that stops needing it). Host call sites are
`D:\manga-list\cls` as of 2026-11-07. `npm run check:nothing-lost` checks the table against the tag.

| Method | Classification | Where it went / why |

| `pluginName` | contract | `WrapperClass.pluginName` and the descriptor's `pluginName`, from the manifest. |

| `credentialSchema` | deleted | A12: the manifest's `credentialOptions.fields` — `username`, `password`, `client_id`, `client_secret`, the same keys, so stored credentials keep working. Host reads at `apipluginhandler.cjs:216`, `:3504`, `pluginservice.cjs:690` move to the descriptor in Phase 5a. |

| `initialize` | contract | Generated; returns `{ status: 'ok' }`. |
